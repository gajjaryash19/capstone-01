# frontend (owner: M4)
React + TypeScript + Vite, Tailwind/shadcn/ui, Recharts, TanStack Query.

## One-time scaffold (run from repo root, once, by M4)
    npm create vite@latest frontend -- --template react-ts
    cd frontend && npm install
Then add the remaining libraries task by task (M4-01..), not all at once.

Must provide: `npm run lint`, `npm run build` (CI runs both; `npm test` when added).
